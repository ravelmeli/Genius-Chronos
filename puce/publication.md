## ➤ Description de la video : 

Comment la puce de ta carte bancaire empêche la copie ? Expliqué en 63 secondes.

Tu paies avec ta carte et la puce sécurise le paiement. Pourquoi est-elle si difficile à copier ? La réponse tient en une idée : la puce ne donne jamais son secret, elle prouve qu'elle le connaît. Voici comment :

💳 La bande magnétique : autrefois, elle contenait des données fixes. Quelqu'un pouvait les lire et en faire une copie.
🔑 La clé secrète : dans la puce, il y a un petit processeur sécurisé. À l'intérieur, une clé secrète qui est enregistrée là et ne ressort jamais.
🧮 Le code : quand tu paies, le terminal envoie à la puce les informations de la transaction, comme le montant. La puce les mélange avec sa clé et calcule un code, valable pour cette transaction seulement. La banque, qui connaît aussi la clé, refait le calcul : si les deux codes sont identiques, le paiement est accepté. Si un pirate enregistre ce code, il est inutile : à chaque paiement, les informations changent, donc le code change aussi.

À savoir : une clé qui ne sort jamais, un code différent à chaque paiement : voilà le secret.
